# Publication adaptation

This is a source-focused extraction of the belt-drive engineering/shader baseline and its later action-film companion. The sibling engineering/shader layout is retained. The action overlay is at `action/`; use `ARX_ACTION_SOURCE_ROOT` as shown in the root README.

## Nonphysical normalization

Seven retained files contained an internal catalog-PDF location or local report paths. Those path strings were replaced by the catalog basename or repository-relative location. They were metadata, not executable input paths or physical parameters. Original download/archive identity remains separate from this publication copy.

Changing these bytes changes content fingerprints. References to affected SHA-256 values were transitively rebased so current-source identity checks remain consistent. These adapted hashes identify this publication copy, not the original delivered archive. This operation did not recalculate a physics trajectory or revalidate the machine. Numeric states, mechanical dimensions, actuation values, acceptance thresholds and outcomes were preserved.

Historical reports therefore remain historical simulation/media findings with adapted path/hash metadata. Source-first publication is not a claim of a new simulation, exact original archive reconstruction or fresh rendering certification. The original archive packaging scripts and manifests are not part of this extraction.

## Omitted generated material

- Generated native STEP/STL exports, reproducible from `generate_cad_p2.py` and `export_p5_assembly.py`.
- Duplicate diagnostic trajectories and high-rate event arrays; source, summaries, metrics and explicit fault conclusions remain.
- Full inspection movie and most chapter movies, reproducible from the retained shader/film tools. The original first chapter is retained because the action companion requires it.
- Large generated offline HTML, reproducible with `tools/build_viewer_p5.py` from the retained source/runtime assets.
- Private browser execution logs and archive-packaging metadata.

All 28 current engineering scenario records are retained, including failures and deliberate controls. The source and data are intended for inspection and reproducibility work, not direct machine deployment.
